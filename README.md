# Acolhe Norte — Cuidado Humanizado para Idosos

Plataforma web desenvolvida em **React + Vite** para conectar famílias de Manaus e da Região Norte a cuidadores de idosos verificados, com foco em acolhimento, segurança e flexibilidade de plantões.

## Funcionalidades

- **Vitrine de Cuidadores em Destaque**: Busca por bairro de Manaus e filtro por turno (Plantão 12x36, Diurno, Noturno, Diárias / Flexível, Integral).
- **Para Famílias**: Formulário completo de solicitação de cuidado salvando no `localStorage`, com feedback visual e envio opcional do resumo direto via WhatsApp.
- **Sou Cuidador**: Cadastro profissional com adição automática e imediata do perfil na vitrine da página inicial.
- **Painel Administrativo**: Visualização consolidada de solicitações das famílias e cuidadores cadastrados, contato rápido via WhatsApp e exclusão de registros.

## Como executar localmente

```bash
npm install
npm run dev
```
